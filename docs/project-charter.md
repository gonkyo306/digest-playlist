# プロジェクト憲章：お気に入り曲のダイジェスト・プレイリストアプリ

作成日：2026-09-27
更新日：2026-10-03
ステータス：運用中（仕様は acceptance-criteria.md を参照）

## コンセプト
**プレイリストをすぐ作って、ダイジェスト再生で、好きな音楽をたくさん浴びられる。** そんな体験ができる、シンプルなアプリ。

- すぐ作れる：検索して、タップするだけで、プレイリストができる。
- ダイジェスト再生：各曲の試聴音源（約30秒）をつないで、次々に流れる。1曲ずつ選ばなくても、好きな曲が連続して耳に入る。
- たくさん浴びる：短い曲をテンポよくつなぐことで、短い時間でも多くの好きな曲に触れられる。
- シンプル：機能は絞り、迷わず使える。機能を足すときは、このコンセプトに沿うかを判断基準にする。

## 1. 目的
Apple Musicで聴いている好きな曲を集めて、プレイリストのように連続で聴けるようにする。曲順は再生のたびにランダムとする。
個人利用（自分）が目的で、ストア公開はしない。

## 2. 利用者
- 自分（Androidユーザー）

→ Androidで使えることが必須条件。iPhoneは対象外。

## 3. 利用シーン
通勤中や家事の合間に、アプリを開いてお気に入りのプレイリストをすぐ再生する。
気分に合わせて曲を追加・削除して、プレイリストを育てていく。再生のたびに曲順が変わるので、毎回違う流れで楽しめる。

## 4. 主な機能
1. 曲を検索して、プレイリストに追加・削除できる
2. プレイリストの曲を、毎回ランダムな順番で自動連続再生できる（手動の並べ替えは不要）
3. 作ったプレイリストを保存し、いつでも呼び出せる

## 5. 曲データの方針
- Appleが無料で公開している試聴音源（約30秒）を利用する
- 曲全体ではなく、各曲の「ダイジェスト」をつなぐ形になる

## 6. 制約・前提
- ストア公開はしない（個人利用のみ）
- Androidのみ対応（iPhoneは対象外）
- 対象端末：Galaxy S26（Android 16）、Chrome
- PWAはGitHub PagesにHTTPSで配置し、URLを知っていれば誰でも開ける（アクセス制限なし）
- 実装言語は素のJavaScript（HTML/CSS/JavaScriptのみ、ビルド不要）とする
- 画面オフ・バックグラウンドでの連続再生は必須要件とする（クロスフェードは、両立しない場合に省略してよい）
- 受入基準の測定条件は、Wi-Fi・モバイル回線のどちらでも動作すること。外部への通信は、配信元（GitHub Pages）を除き、曲の検索・情報取得と試聴音源の取得のみ
