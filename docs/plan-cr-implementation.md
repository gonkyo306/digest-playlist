## この計画の考え方
- 今回のCR-001〜CR-008は、**「検索画面をプレイリストから独立させる」（CR-006）**と**「再生をプレイリスト詳細画面のライフサイクルから切り離す」（CR-003）**という、既存実装の前提を変える2つの構造変更を土台にしています。他のCR（検索方式の拡張、無限スクロール、アルバム一時再生、カート）は、この2つの土台の上に乗る機能なので、先に着手します。
- 見た目の変更のみで依存の少ないもの（アーティスト順ソート＝CR-004、アイコン化＝CR-002）は、構造変更のあとに仕上げとして行います（アイコン化は特に、ミニプレイヤー等の新規UIも対象に含めるため、UIが出そろってからの方が手戻りが少ないと判断）。
- フェーズ番号はplan.mdの続き（フェーズ7〜）としています。
