# 改修要望フォーム：お気に入り曲のダイジェスト・メドレーアプリ

作成日：2026-09-27
用途：使っていて気づいた不具合・直してほしい点・追加してほしい機能を記録しておくためのメモです。気づいたときに、下の表へ1行ずつ追記してください。まとまった数がたまったら、対応の要否・優先順位を相談して進めます。

## 書き方

| 項目 | 説明 |
|---|---|
| ID | 連番（CR-001、CR-002…）。採番はどちらが記入してもOK |
| 日付 | 気づいた日（YYYY-MM-DD） |
| 種別 | 不具合 ／ 改善要望 ／ 新機能 のいずれか |
| 内容 | 何が起きたか・何をどうしてほしいか。不具合の場合は、できれば再現手順も書く |
| 優先度 | 高 ／ 中 ／ 低（未記入でも可） |
| 状態 | 未着手 ／ 対応中 ／ 完了 ／ 却下（記入時点では「未着手」でよい。対応時に更新） |
| 備考 | 関連する画面・対応基準ID（acceptance-criteria.mdのFR/NFR番号）など、あれば |
