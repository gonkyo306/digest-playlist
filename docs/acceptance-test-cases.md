## 4. 優先度に関する補足
- 画面オフ・バックグラウンドでの連続再生（NFR-4.5）は必須要件です。TC-NFR-4.5-1（クロスフェード付き）が最優先の確認事項です。
- クロスフェード（FR-4.7）は、画面オフ再生と両立しない場合に優先度を下げてよい項目です。その場合、TC-FR-4.7-1・TC-NFR-1.3-1は不合格でも受入不可とはしません。TC-NFR-4.5-2でクロスフェードなしの画面オフ再生を確認してください。
- 再生中の曲取得失敗は、3曲連続で失敗した場合のみ停止・エラー表示とします（TC-FR-4.15-1、TC-FR-4.15-2）。2曲までの連続失敗はスキップして継続します。
- クロスフェードを省略してもなお画面オフ再生が成立しない場合は、Androidネイティブアプリへの切り替えを検討する必要があります（要相談。project-charter.md参照）。
