# 受入テストケース一覧：Playlish（お気に入り曲のダイジェスト・プレイリストアプリ）

更新日：2026-10-03
根拠：acceptance-criteria.md（機能要件 FR、非機能要件 NFR）
表記：「対応基準」は acceptance-criteria.md の ID です。「結果」欄は実施時に ○／×／備考 を記入してください。

## 実施状況
- 正式な受入テストは未実施のため、結果欄はすべて空欄です。各機能のロジックはUnitテスト（`npm test`）と、PCのブラウザでのE2Eテスト（`npm run test:e2e`。自動スクロール、編集モード、作成・検索・追加など）で確認していますが、実機（Galaxy S26）での見た目・操作感・実際の音の確認は、このテストケースで行います。
- 実機でのみ確認できる項目：画面オフ・バックグラウンド再生（TC-NFR-4.5-1、TC-NFR-4.5-2、TC-FR-4.7-1、TC-FR-4.12-1〜3、TC-NFR-2.1-1、TC-NFR-1.3-1）、ホーム画面アイコン・通知アイコン（TC-FR-4.12-4）、ダーク／ライト切替（TC-FR-5.1-1）、タップ領域・片手操作（TC-NFR-5.1-1、TC-NFR-5.2-1、TC-NFR-5.7-2、TC-NFR-5.8-2）、画面下部の青い線・帯（TC-FR-6.1-11）、旧版データの引き継ぎ（TC-NFR-3.5-1）、端末再起動後のデータ保持（TC-NFR-3.2-1）、モバイル回線での検索時間（TC-NFR-1.1-2）。
- 開発者ツールが必要な項目（PCのChromeから端末をリモートデバッグして実施）：TC-FR-3.1-1、TC-FR-3.2-1、TC-FR-3.2-2、TC-FR-3.3-1、TC-FR-3.3-2、TC-FR-4.15-1、TC-FR-4.15-2、TC-NFR-3.6-1、TC-NFR-6.2-1。
- TC-NFR-4.1-1（全項目まとめての合否判定）は、上記すべての完了後に判定します。

## 0. 実施条件

- 端末：Galaxy S26（Android 16）、Chrome（最新版）
- 配信：GitHub Pages の URL（HTTPS）から開く（`https://gonkyo306.github.io/digest-playlist/`）
- 回線：Wi-Fi とモバイル回線の両方（回線を指定していないテストは、Wi-Fi で実施）
- 事前に用意するもの：
  - プレイリスト A（20曲以上、曲名・アーティストが異なる曲）
  - プレイリスト B（1曲のみ）
  - プレイリスト C（0曲）
  - プレイリスト D（TC-FR-2.4-2/2.4-3の「前回追加」確認用に、もう1つ）
  - 試聴音源がない曲（FR-1.4 用）
  - 同じ曲の別収録版（シングル版とアルバム版など、FR-2.6 用）
  - 複数のアルバムを持つアーティスト、複数曲を持つアルバム（FR-1.9用）
  - 曲・アーティスト・アルバムが混在してヒットするキーワード（FR-1.8、TC-FR-1.2-2用）
  - 長い曲名・プレイリスト名（NFR-5.12用）
- 先行して実施するテスト：TC-NFR-4.5-1、TC-FR-4.12-1（画面オフ・バックグラウンドでの連続再生は必須要件。PWA の制約に左右されるため、最初に検証する。クロスフェード付き（TC-FR-4.7-1）で通らない場合は、クロスフェードなしで画面オフ再生が成立するかを確認する（TC-NFR-4.5-2））
- 開発者ツールを使うテスト（TC-FR-3.2-1、TC-FR-3.3-1、TC-FR-3.3-2、TC-NFR-6.2-1等）は、PC の Chrome から端末をリモートデバッグして実施する

## 4. 優先度に関する補足
- 画面オフ・バックグラウンドでの連続再生（NFR-4.5）は必須要件です。TC-NFR-4.5-1（クロスフェード付き）が最優先の確認事項です。
- クロスフェード（FR-4.7）は、画面オフ再生と両立しない場合に優先度を下げてよい項目です。その場合、TC-FR-4.7-1・TC-NFR-1.3-1は不合格でも受入不可とはしません。TC-NFR-4.5-2でクロスフェードなしの画面オフ再生を確認してください。
- 再生中の曲取得失敗は、3曲連続で失敗した場合のみ停止・エラー表示とします（TC-FR-4.15-1、TC-FR-4.15-2）。2曲までの連続失敗はスキップして継続します。
- クロスフェードを省略してもなお画面オフ再生が成立しない場合は、Androidネイティブアプリへの切り替えを検討する必要があります（要相談）。
